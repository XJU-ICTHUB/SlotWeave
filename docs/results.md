## 是否引入了明显额外耗时

所有编译、轨迹和安全性任务结束后，串行执行6组固定压力输入。每组3轮ABBA，即“参考、整理版、整理版、参考”，比较init+ops中位数。

整理版/参考版的中位数比值为 **0.9860～1.0017**，本次本地检查未见明显额外耗时。各输入结果如下：

| 输入类别 | init+ops中位数比值 |
|---|---:|
| 大批量操作 | 0.9987 |
| 高负载 | 1.0017 |
| 反复增删 | 0.9981 |
| 大规模批量操作（二） | 0.9860 |
| 中等规模 | 0.9995 |
| 小N长Q压力 | 0.9955 |

这是单机测量，不保证任意机器或官方环境的速度分一致，也不把略小于1的值作为算法加速结论。

## 本地指标的含义

运行器的 `quality` 是 `0.55×mean(U)+0.35×mean(V)`，不含需要参考耗时的速度项。布局质量、接口正确性和运行成本是不同指标，应分别检查。

上述结果记录有限输入上的实际验证范围；逐步轨迹一致和单机耗时对照不构成任意输入上的等价性或性能保证。
