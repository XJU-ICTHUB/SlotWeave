## 与原强版本相比损失了多少

旧458行compact版不仅去掉特化，也删掉了主要通用优化，在318例相同校准输入上的本地质量均值低约0.034862。这是本次保留完整引擎的原因。

当前完整通用版在同318例上，比带样例路径和后期参数的原强父本平均低约0.001032。其中主要部分是公开样例不再使用预存路径。去掉样例后，剩余306例的本地质量平均差仅约 **−0.00001923**。

这些是 `J=0.55U+0.35V` 的本地差异，没有官方速度项。原父本缓存指标保留6位小数，因此比较还有约10⁻⁶量级的量化误差。它们说明通用能力保留得更完整，不能直接翻译成官方总分。

## 是否引入了明显额外耗时

所有编译、轨迹和安全性任务结束后，串行执行6组固定压力输入。每组3轮ABBA，即“参考、整理版、整理版、参考”，比较init+ops中位数。

整理版/参考版的中位数比值为 **0.9860～1.0017**，本次本地检查未见明显额外耗时。各输入结果如下：

| 输入类别 | init+ops中位数比值 |
|---|---:|
| 大批量操作 | 0.9987 |
| 高负载 | 1.0017 |
| 反复增删 | 0.9981 |
| 大规模批量操作（二） | 0.9860 |
| 中等规模 | 0.9995 |
| 小N长Q压力 | 0.9955 |

这是单机测量，不保证任意机器或官方环境的速度分一致，也不把略小于1的值作为算法加速结论。
